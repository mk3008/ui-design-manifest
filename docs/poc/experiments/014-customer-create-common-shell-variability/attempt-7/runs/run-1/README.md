# Customer create — run 1

Static, local-only customer-create page using the supplied common shell and manifest guidance.

Open `index.html` in a browser. Optional query parameters preserve the supplied shell experiment states:

- `?drawer=open|hidden`
- `?theme=light|dark`

The form validates required fields, date format, telephone-number format, and email-address format in the browser. The Save control intentionally performs no persistence, data connection, navigation, or permission check.
