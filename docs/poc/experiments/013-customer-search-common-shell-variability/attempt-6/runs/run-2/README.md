# Run 2 — Customer search

Local-only static customer-search experiment using the supplied common Header and Drawer shell.

Open `index.html` in a browser. Optional URL parameters preserve the shell experiment states:

- `?drawer=open|hidden`
- `?theme=light|dark`

The page presents six neutral customer fixtures. Search, reset, customer-ID detail confirmation, add-customer, theme, and Drawer controls are available as static interactions; no persistence, results processing, routing, permission handling, or data connection is implemented.
