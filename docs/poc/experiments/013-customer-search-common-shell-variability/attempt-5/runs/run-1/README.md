# Customer search — run 1

Local-only static implementation of the supplied common Header and Drawer shell.

Open `index.html` directly. Optional query parameters are retained from the shell:

- `?drawer=open|hidden`
- `?theme=light|dark`

The page presents six neutral customer fixtures, search conditions, a result count,
and pagination controls. Search, add-customer, detail, and pagination controls are
intentionally non-navigating static affordances; no data, execution, persistence,
permissions, or result changes are implemented.
