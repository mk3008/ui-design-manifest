# Customer search static showcase

Self-contained static customer-search screen based on the supplied Japanese prompt and design-manifest guidance.

## Included behavior

- Searches the displayed fixture records by name, birth date, phone number, and email address.
- Clears the declared search conditions.
- Opens a read-only customer detail dialog from the primary identity link.
- Keeps customer ID visibly read-only and presents the fixed management fields: name, birth date, address, phone, email, and notes.
- Includes a labelled light/dark theme toggle, semantic HTML, visible keyboard focus, and text-based empty-state feedback.

## Run

Open `index.html` directly in a modern browser. No build, network request, external asset, or dependency is required.
