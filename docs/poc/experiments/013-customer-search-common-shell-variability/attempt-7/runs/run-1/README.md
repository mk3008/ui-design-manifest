# Customer search — Run 1

Static HTML implementation of the supplied customer-search fixture and common shell.

Open `index.html` in a browser. The supplied shell supports these optional query parameters:

- `?drawer=open|hidden`
- `?theme=light|dark`

Search, reset, record-opening, add-customer, and pagination controls are presented as static affordances. They do not save data, execute queries, navigate, or connect to a data source.
