# Run 3

Static customer-search screen built only from the supplied design manifest,
common shell, and fixed Japanese prompt.

Open `index.html` locally. The common shell supports optional query parameters:

- `?drawer=open|hidden`
- `?theme=light|dark`

The six customer records are neutral fixtures. Search, add, detail, and
pagination controls are visible static affordances; they do not save, execute
data operations, navigate, or connect to a data source. The Reset control only
clears the local form fields.
