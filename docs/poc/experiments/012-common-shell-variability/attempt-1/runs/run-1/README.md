# Run 1 — Common shell

A standalone light-theme static prototype containing only a Header and a Drawer.

Open `index.html?drawer=open` to begin with the Drawer visible, or
`index.html?drawer=hidden` to begin with it omitted. The leading Header control
can toggle the Drawer during inspection.

All styling and behavior are local to `styles.css` and `app.js`; the prototype
uses no external assets, fonts, scripts, or network resources.
