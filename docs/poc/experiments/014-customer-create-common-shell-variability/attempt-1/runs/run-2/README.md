# Run 2

A local-only static customer-create screen built from the supplied design manifest, common shell, and fixed Japanese product prompt.

Open `index.html` in a browser. The shared shell supports the supplied optional query parameters:

- `?drawer=open|hidden`
- `?theme=light|dark`

The form performs in-page required, date, phone-number, and email-format validation. The Save button only validates input; it does not persist data, connect to a service, navigate, or evaluate permissions.
