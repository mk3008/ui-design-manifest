# Customer search static specimen

Self-contained Japanese customer-search page built from the supplied consumer input.

## Run

Open `index.html` in a modern browser. No build, server, external assets, or network requests are required.

## Included behavior

- Search by name, date of birth, phone number, or email address; clear the active conditions.
- Scan a compact, paginated result grid; sort by customer name.
- Open an accessible native-dialog read-only customer detail from the primary identity link.
- Switch between light and dark semantic color themes.

The sample customer data is illustrative. Customer IDs are displayed as fixed internal identifiers and have no editing interface.
