# Run 3

Static customer-create screen produced from the supplied design manifest, common shell, and fixed Japanese product prompt.

Open `index.html` in a browser. Optional shell parameters are retained from the supplied shell:

- `?drawer=open|hidden`
- `?theme=light|dark`

The Save control performs client-side required, date, telephone, and email-format validation only. It does not persist data, connect to a service, or navigate.
