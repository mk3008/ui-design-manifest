# Customer search — Run 3

Local-only static prototype for the fixed customer-search prompt. It reuses the supplied shared Header and Drawer behavior, including query-string preview states:

- `?drawer=open|hidden`
- `?theme=light|dark`

The six displayed records are neutral fixtures. Search, reset, add, detail, and pagination are present as UI affordances only; no customer data, persistence, execution, or navigation is implemented.
