# Run 2: Common shell

Static Header and Drawer specimen for the fixed prompt.

Open `index.html` with either query combination:

- `?drawer=open&theme=light`
- `?drawer=open&theme=dark`
- `?drawer=hidden&theme=light`
- `?drawer=hidden&theme=dark`

The leading icon button toggles the Drawer, and the trailing icon button switches the theme. Both controls update the query string to reflect the active state. The page has no external dependencies.
