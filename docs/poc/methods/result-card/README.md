# Purpose

Use this method for a search-result card collection, not a result grid. It separates the decision to use cards from table/list presentation, records only bounded visual evidence, and preserves unresolved product behavior.

# Method

1. Start with [observation schema](observation-schema.md) and classify every axis.
2. Record evidence and non-evidence in an observation record without promoting it to a universal rule.
3. Apply the [extraction template](extraction-template.md) and evaluate it with the [first-pass rubric](first-pass-rubric.md).
4. Produce a source-blind Manifest, an Application Input Contract, and an apply instruction.

Use [extraction prompt](extraction-prompt.md) only for a declared, bounded source input.
