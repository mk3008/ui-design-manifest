# Run 3: Common shell fixture

This static fixture implements only the requested Header and Drawer shell.

- `?drawer=open` renders the Drawer initially visible.
- `?drawer=hidden` renders the Drawer initially hidden, with no remaining Drawer boundary or reserved layout space.
- The Header control toggles visibility during the session.

The fixture has no external assets, fonts, stylesheets, scripts, product data, or routed screens.
