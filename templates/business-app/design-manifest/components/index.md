# Components

- [Drawer](drawer.md) - Separate available navigation from the workspace and Header controller.
- [Search conditions](search-conditions.md) - Bound a query task and its primary and clearing actions.
- [Result grid](result-grid.md) - Support scanning a result set without owning its data meaning.
- [Result card](result-card.md) - Support identity-oriented, heterogeneous record summaries.
- [Pagination](pagination.md) - Continue a declared result set without inventing its count or page state.
- [Status badge](status-badge.md) - Express a short record state without relying on color alone.
