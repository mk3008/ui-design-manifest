# Apply

1. Validate the Application Input Contract; omit dependent UI or stop for a product decision when an input is absent.
2. Render inspection before editing: identity, summary, and captioned attribute groups in the supplied presentation mode.
3. Place only supplied record actions near the record context. Use Back to results only for a full page and Close only for a dismissible overlay.
4. For an available medium-impact delete, open a separate confirmation with the Contract-supplied identity and consequences. Disable repeat execution while pending.
5. For an unavailable delete, render or omit it according to the supplied reason and policy. Do not substitute a disabled edit form, typed confirmation, undo, or an outcome destination.
