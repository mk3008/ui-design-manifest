# Prompt

Given a declared single-record inspection state and a separately declared deletion state, classify every schema axis. Preserve uncertainty. Produce no original labels, identities, visual tokens, or interaction behavior that the declared scope does not establish. State whether the detail is full-page, modal, or drawer; then apply the corresponding return or Close convention only when the presentation mode supports it.
