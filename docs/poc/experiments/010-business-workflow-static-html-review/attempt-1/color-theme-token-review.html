Color and theme values

Supplement · editable manifest palette

Canonical defaults

Fixed roles, editable concrete values

The manifest fixes each role’s meaning and supplies one concrete value for Light and Dark. A consuming team may replace the values through one reviewed local override without adding roles or changing their meaning.
