# Customer search specimen

Self-contained static customer-search screen based on the supplied Japanese request and manifest inputs.

## Run

Open `index.html` in a modern browser. No build step, external request, asset, font, or dependency is used.

## Included behavior

- Filters the local illustrative customer fixture by name, birth date, telephone number, and email address.
- Clears all conditions and restores the full result set.
- Shows the fixed customer management fields in a dense, scan-oriented result grid; customer IDs are display-only.
- Uses the manifest's light/dark semantic color values via the browser's color-scheme preference.
