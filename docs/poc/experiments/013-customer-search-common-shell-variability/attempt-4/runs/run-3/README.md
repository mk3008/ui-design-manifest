# Run 3 — Customer search

Self-contained static HTML fixture for the supplied customer-search prompt.

Open `index.html` locally. The shared shell accepts optional query parameters:

- `?drawer=open|hidden`
- `?theme=light|dark`

The search, reset, add-customer, detail, and pagination controls are visual fixtures only. No data access, search execution, save, navigation, authorization, or outcome behavior is implemented.
