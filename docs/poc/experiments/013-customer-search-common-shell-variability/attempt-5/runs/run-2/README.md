# Customer search — Run 2

Static, local-only customer-search experiment using the supplied shared Header and Drawer shell.

Open `index.html` in a browser. The supplied shell controls support:

- `?drawer=open|hidden`
- `?theme=light|dark`

The customer records are six neutral fixtures. Search, reset, customer-detail links, add-customer link, and pagination are present as UI capabilities only; no persistence, query execution, navigation destination, permission handling, or result-state behavior is implemented.
