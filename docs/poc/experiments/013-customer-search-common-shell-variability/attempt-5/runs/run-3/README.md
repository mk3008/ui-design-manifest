# Customer search — Run 3

Local-only static customer-search specimen using the supplied common Header and Drawer shell.

Open `index.html` in a browser. The shared shell supports these optional query parameters:

- `?drawer=open|hidden`
- `?theme=light|dark`

The search, reset, add, paging, and customer-detail controls are present as static capability evidence only. No persistence, query execution, navigation, permission evaluation, or result updates are implemented.
