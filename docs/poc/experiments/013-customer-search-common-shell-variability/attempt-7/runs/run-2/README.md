# Run 2: Customer search

Static customer-search implementation using the supplied shared Header and Drawer shell.

Open `index.html` in a browser. Optional query parameters retain the shared-shell experiment behavior:

- `?drawer=open|hidden`
- `?theme=light|dark`

This fixture presents six neutral customer records. Search, reset, customer-detail, add-customer, and pagination controls are intentionally non-persistent and do not execute, navigate, or connect to data.
