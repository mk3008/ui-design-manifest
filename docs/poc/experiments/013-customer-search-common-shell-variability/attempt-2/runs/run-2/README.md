# Customer search static specimen

Open `index.html` in a browser. The page is a self-contained static customer-search specimen with six neutral fixture rows.

- `?drawer=open` or `?drawer=hidden` sets the initial Drawer state.
- `?theme=light` or `?theme=dark` sets the initial theme.

The Header controls remain interactive for demonstrating the fixed common-shell states. Search, Clear, customer links, add customer, and pagination are display-only fixtures; no record operation, data connection, or navigation is implemented.
