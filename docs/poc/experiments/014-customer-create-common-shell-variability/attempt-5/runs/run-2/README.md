# Run 2: customer create

A local-only static customer-creation screen that reuses the supplied shared shell.

Open `index.html` in a browser. Optional query parameters preserve the shell experiment controls:

- `?drawer=open|hidden`
- `?theme=light|dark`

The Save action performs only client-side required-field and format validation. It does not save data, connect to a data source, navigate, or evaluate permissions.
