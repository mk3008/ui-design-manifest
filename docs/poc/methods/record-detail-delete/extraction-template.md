# Worksheet

Record presentation mode, host relationship, visible information groups, hierarchy, label/value treatment, read-only semantics, and the return or dismissal affordance. Separately record delete trigger placement, impact, digest contents, consequences, reversibility, confirmation requirement, pending/error/success behavior, unavailable reason, and post-delete destination.

For each claim, state its status, ownership class, viewport or declared state, and limit. Put missing product meaning in the Application Input Contract rather than promoting it from a static observation.
