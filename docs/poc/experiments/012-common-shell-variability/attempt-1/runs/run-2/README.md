# Run 2: Common shell fixture

This is a static, light-only common shell containing only the Header and Drawer.

Open `index.html?drawer=open` to start with the Drawer visible, or
`index.html?drawer=hidden` to start with it omitted. The Header control toggles
the Drawer and updates the query parameter.

All assets are local: `index.html` references only `styles.css` and `app.js`.
